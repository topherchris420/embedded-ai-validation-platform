# Embedded AI Validation Platform - Agent Guidelines

## Agent skills

### Issue tracker
Issues are tracked as local markdown files under `.scratch/<feature>/issues/`. See `docs/agents/issue-tracker.md`.

### Triage labels
Standard five-role triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs
Single-context repository layout with `CONTEXT.md` at root and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
